## English

Notchy is a free Windows app that brings a Dynamic Island and a Control Center to the desktop. The official build is a closed-source installer. It includes the launcher, the island, and search.

### Requirements

- Windows 10 or Windows 11
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (Evergreen). Windows 11 usually already has it.

### Download

1. Open [Releases](https://github.com/TechTurtle192/Notchy/releases).
2. Download `Notchy-Setup.exe` from the latest release.
3. Run the installer.

This repository does not contain application source code. Notchy is closed source and distributed only as the official installer.
